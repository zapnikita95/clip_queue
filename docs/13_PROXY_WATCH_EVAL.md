# Оценка: просмотр YouTube через прокси (платно)

**Статус:** не делаем сейчас. Оценка для продукта.

## Зачем

В РФ YouTube без VPN часто недоступен. Идея: за доплату стримить ролик через прослойку Kyro.

## Сложность

| Слой | Оценка |
|------|--------|
| Резолв стрима (yt-dlp / Invidious-like) | Высокая, постоянный ops |
| In-app player (Media3) | Средняя, 1–2 недели |
| Egress / CDN | Высокая; Railway не подходит |
| Billing | Средняя, с нуля |
| ToS / баны IP | Критично |

Объём MVP: **~4–8 недель** + вечная поддержка экстрактора.

## Деньги / нагрузка

- 720p ≈ 0.7–1.5 ГБ/ч; 1080p ≈ 1.5–3 ГБ/ч.
- 100 юзеров × 5 ч/мес × ~1.5 ГБ ≈ **~750 ГБ/мес**.
- Egress часто $5–20 / ТБ → легко сотни $/мес при росте.
- Себестоимость легко съедает подписку 99–299 ₽ без квот и низкого качества.

## Рекомендация

Сначала share + classify push. Proxy — отдельный stream-сервис с квотами, не Flask на Railway.
